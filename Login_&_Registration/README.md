# PHP Login & Registration System (JSON-Based)

A simple and beginner-friendly **Login and Registration system** built using **PHP**, **Sessions**, and a **JSON file** as the database.  
No MySQL or external DB required — perfect for learning authentication basics.

---

## 🚀 Features

- 🔐 User Registration  
- 🔑 Secure Login (with `password_hash()` + `password_verify()`)  
- 🧾 User data stored in a JSON file  
- 👤 Personalized Dashboard  
- ✔️ Form Validation  
- 🔒 PHP Sessions for authentication  
- 🚪 Logout functionality
